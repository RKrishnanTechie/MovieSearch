# 🎬 MovieHunt – Full Stack Movie Search App

A responsive web app for movie discovery built using the MERN stack. Users can search for movies, filter by genre, and access streaming availability with secure login.

## 🔧 Tech Stack
- **Frontend**: React, SCSS, Context API
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Authentication**: JWT, OAuth2
- **APIs**: TMDB (The Movie Database)
- **Tools**: Postman, GitHub, Netlify/Vercel (optional)

## ✨ Features
- Search movies by title and genre
- Secure login with JWT-based authentication
- Responsive UI (optimized for desktop)
- Voice-based movie search (accessibility feature)
- Integration with TMDB for real-time data
